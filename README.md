# Space Shooter (Pygame)

A 2D Space Shooter game built with Python and Pygame.

## Features
- Player spaceship with directional controls & shooting
- Enemy spawning with adaptive difficulty
- Sound effects for hits and Game Over screen
- Interactive restart (R) and quit (Q) buttons

## Prerequisites
- Python 3.x
- Pygame (`pip install pygame`)

## How to Play
1. Clone the repository: `git clone https://github.com/YOUR-USERNAME/space-shooter.git`
2. Run `python main.py`
3. Controls:
   - **Left / Right Arrows**: Move ship
   - **Spacebar**: Shoot
   - **R**: Restart game
   - **Q**: Quit game
